# OOP Basics

## Day 6

### Day 6 — Demo program

### Goal of the day
Build a full demonstration of the banking system in action.

### Requirements

#### 1. Initialization
- create a bank
- clients (5–10)
- accounts (10–15)

#### 2. Simulation
- 30–50 transactions
- some failed
- some suspicious

#### 3. Logging
- show queue entry
- execution
- rejection

#### 4. User scenarios
- show client accounts
- history
- suspicious operations

#### 5. Reports
- top-3 clients
- transaction statistics
- total balance
