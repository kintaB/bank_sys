# OOP Basics

## Day 5

### Day 5 — Audit and risk analysis

### Goal of the day
Create an audit and risk-analysis system for monitoring banking operations security.

### Requirements

#### 1. Class `AuditLog`
- severity levels
- save to memory and file
- filtering

#### 2. Class `RiskAnalyzer`
Detect suspicious operations:
- large amount
- frequent operations
- transfers to new accounts
- night operations

Risk levels: low, medium, high

The bank must block dangerous operations.

#### 3. Audit reports
- suspicious operations
- client risk profile
- error statistics

#### 4. Testing
Create a set of normal and suspicious transactions.
